# 🪨📄✂️ Rock Paper Scissors Game (Kotlin)

This is a simple implementation of the classic Rock-Paper-Scissors game written in Kotlin. The game allows a player to choose between Rock, Paper, or Scissors, and pits their choice against a randomly generated move from the computer.

# 💡 Game Rules
Rock beats Scissors

Scissors beats Paper

Paper beats Rock
